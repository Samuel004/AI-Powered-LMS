AI-Powered Learning Management System

This is a full-stack AI-powered Learning Management System that enables students, instructors, and administrators to manage courses, conduct live classes, and enhance learning through AI-powered features such as notes generation and quizzes.

Features

- Secure JWT authentication and role-based access (Student, Instructor, Admin)
- Course, lesson, and enrollment management
- Student progress tracking
- AI-generated notes and quizzes using Google Gemini
- Live classes with real-time video and chat
- Secure payments with Stripe
- Media uploads using Cloudinary
- Responsive and modern UI

Tech Stack

Frontend
- React
- Vite
- Tailwind CSS
- shadcn/ui
- React Router
- Axios
- Socket.IO Client
- WebRTC (simple-peer)

Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Stripe
- Cloudinary
- Multer
- Google Gemini API
